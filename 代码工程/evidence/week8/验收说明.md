### 对模型回答的人工纠正

1. `get_time` 的 `timezone=UTC` 表示该工具输出采用 UTC，不能据此判断服务器配置的本地时区。
2. `get_memory_info` 是系统内存快照，未采集进程 RSS；模型引入的 RSS 共享页讨论不能用来解释本次 `used` 指标。
3. `schedstats` 用于调度统计，并非观测内存压力或缺页的必要前提；后续内存验证应连续采样，并按需要读取缺页、换页和内存压力指标。

以上纠正未改写模型原始响应。

## 通信链路说明

Host 发起请求，通过 MCP Client 按 `stdio` 启动并连接 Server；Client 先执行初始化与 `tools/list`，再按工具名和 JSON 参数执行 `tools/call`。Server 校验参数，调用操作系统采集函数，并把结构化结果返回给 Client，Host 再读取结果。`stdout` 专供 MCP 消息，日志写入 `stderr`。

当前 16 个工具的注册和模式发现已通过；注册成功不代表学生模块的采集和算法全部完成。后续周次继续实现学生模块。
